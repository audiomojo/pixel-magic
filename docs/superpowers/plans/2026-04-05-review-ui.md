# Review UI (Phase 5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Phase 5 Review UI — a group list page and a full-viewport group review page with thumbnail strip, keyboard shortcuts, and keep/discard resolution flow.

**Architecture:** Two client-component pages. `app/review/page.tsx` fetches pending groups and renders summary cards. `app/review/[groupId]/page.tsx` owns all review state: it fetches the group detail and the full group list, renders a split-viewport layout (action bar + large preview + thumbnail strip + keyboard hints), and POSTs the resolution to `/api/groups/[id]`. No new components — all logic is self-contained in each page file. All images are proxied through `/api/images?path=<encoded-path>`.

**Tech Stack:** Next.js 16.2.2 App Router · TypeScript · Tailwind CSS · shadcn/ui (@base-ui/react) · sonner toasts · lucide-react

---

### ⚠️ Before Starting

Read `node_modules/next/dist/docs/01-app/03-api-reference/04-functions/use-params.md` — `useParams<{ groupId: string }>()` returns the dynamic segment synchronously as a plain object (no `.then()`). This differs from route handler params which are `Promise<{ id: string }>`.

The dev server must be running (`npm run dev`, port 3001). After each task verify visually in the browser.

## Task 1: Group List Page

**Files:**
- Modify: `app/review/page.tsx`

- [ ] **Step 1: Replace `app/review/page.tsx`**

This page fetches `/api/groups` (returns `ImageGroup[]` of pending groups only), renders a card per group, and shows an empty state when all groups are reviewed.

The `Auto-keep Singletons` button calls `POST /api/singletons` — this moves singleton images to Keeping without changing which groups appear here.

```tsx
'use client';

import { useEffect, useState } from 'react';
import Link from 'next/link';
import { useRouter } from 'next/navigation';
import { toast } from 'sonner';
import { Button } from '@/components/ui/button';
import type { ImageGroup } from '@/types';

export default function ReviewListPage() {
  const router = useRouter();
  const [groups, setGroups] = useState<ImageGroup[] | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch('/api/groups')
      .then((r) => r.json())
      .then((data: ImageGroup[]) => setGroups(data))
      .catch(() => toast.error('Failed to load groups'))
      .finally(() => setLoading(false));
  }, []);

  async function handleAutoKeepSingletons() {
    const res = await fetch('/api/singletons', { method: 'POST' });
    if (!res.ok) {
      toast.error('Failed to auto-keep singletons');
      return;
    }
    const { count } = (await res.json()) as { ok: boolean; count: number };
    toast.success(`Kept ${count} singleton${count !== 1 ? 's' : ''}`);
  }

  if (loading) {
    return (
      <div className="mx-auto max-w-2xl px-4 py-6">
        <div className="space-y-3">
          {[1, 2, 3].map((i) => (
            <div key={i} className="h-20 animate-pulse rounded-xl bg-muted" />
          ))}
        </div>
      </div>
    );
  }

  if (!groups || groups.length === 0) {
    return (
      <div className="mx-auto max-w-2xl px-4 py-16 text-center">
        <p className="mb-4 text-sm text-muted-foreground">
          All groups reviewed — nothing pending.
        </p>
        <Link href="/" className="text-sm text-primary underline underline-offset-2">
          ← Back to Dashboard
        </Link>
      </div>
    );
  }

  return (
    <div className="mx-auto max-w-2xl px-4 py-6">
      <div className="mb-4 flex items-center justify-between">
        <p className="text-sm font-medium">
          {groups.length} group{groups.length !== 1 ? 's' : ''} pending review
        </p>
        <Button size="sm" variant="outline" onClick={handleAutoKeepSingletons}>
          Auto-keep Singletons
        </Button>
      </div>
      <div className="space-y-3">
        {groups.map((group, idx) => (
          <div
            key={group.id}
            className="flex items-center gap-3 rounded-xl border bg-card p-3"
          >
            {/* eslint-disable-next-line @next/next/no-img-element */}
            <img
              src={`/api/images?path=${encodeURIComponent(group.representativePath)}`}
              alt={`Group ${idx + 1} representative`}
              className="h-16 w-16 flex-none rounded-lg object-cover"
            />
            <div className="min-w-0 flex-1">
              <p className="text-sm font-medium">Group {idx + 1}</p>
              <p className="text-xs text-muted-foreground">
                {group.imageCount} image{group.imageCount !== 1 ? 's' : ''}
              </p>
            </div>
            <Button size="sm" onClick={() => router.push(`/review/${group.id}`)}>
              Review →
            </Button>
          </div>
        ))}
      </div>
    </div>
  );
}
```

## Task 2: Group Review Page

**Files:**
- Modify: `app/review/[groupId]/page.tsx`

- [ ] **Step 1: Replace `app/review/[groupId]/page.tsx`**

Key design decisions:
- Layout: `h-[calc(100vh-2.75rem)] flex flex-col overflow-hidden` — the page fills exactly the viewport below the nav (nav = `h-11` = 44px = 2.75rem). No page scroll.
- Action bar: `flex-none`, auto height, above the preview.
- Preview area: `flex-1 min-h-0` — takes all remaining space between action bar and thumbnail strip.
- Thumbnail strip: `h-[25vh] flex-none` — fixed visual height at bottom.
- Keyboard hints bar: `flex-none`, very short.

`useParams<{ groupId: string }>()` returns `{ groupId: string }` synchronously. Convert to number with `parseInt(params.groupId, 10)`.

Data: fetch `GET /api/groups/${groupId}` (→ `{ group: ImageGroup; images: ImageRecord[] }`) and `GET /api/groups` (→ `ImageGroup[]`, pending only) in parallel on mount to compute "Group N of M" and next group navigation.

State:
- `keptPaths: string[]` — paths the user has checked as "keep" (starts empty; unchecked = will be recycled)
- `focusedIdx: number` — which thumbnail is active (shown in large preview; updated by click or arrow keys)

On submit (`handleSubmit(keepPaths)`):
- `recyclePaths` = all image paths NOT in `keepPaths`
- `POST /api/groups/${groupId}` with `{ keepPaths, recyclePaths }`
- On success: navigate to `allGroups[groupIndex + 1].id` or `/review` if last

"Discard All" opens a Dialog for confirmation, then calls `handleSubmit([])`.

"Keep All" sets `keptPaths` to all image paths (user still presses "Keep Selected & Continue" to submit).

Keyboard shortcuts registered with a `window` keydown listener. To avoid stale-closure bugs, `handleSubmit` is wrapped in `useCallback` so the keyboard effect can list it as a dependency.

```tsx
'use client';

import { useCallback, useEffect, useRef, useState } from 'react';
import Link from 'next/link';
import { useParams, useRouter } from 'next/navigation';
import { toast } from 'sonner';
import { Button } from '@/components/ui/button';
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from '@/components/ui/dialog';
import { cn } from '@/lib/utils';
import type { ImageGroup, ImageRecord } from '@/types';

function formatBytes(bytes: number): string {
  if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)} KB`;
  return `${(bytes / (1024 * 1024)).toFixed(1)} MB`;
}

function basename(filePath: string): string {
  return filePath.split('/').pop() ?? filePath;
}

function imageUrl(filePath: string): string {
  return `/api/images?path=${encodeURIComponent(filePath)}`;
}

export default function GroupReviewPage() {
  const params = useParams<{ groupId: string }>();
  const router = useRouter();
  const groupId = parseInt(params.groupId, 10);

  const [group, setGroup] = useState<ImageGroup | null>(null);
  const [images, setImages] = useState<ImageRecord[]>([]);
  const [allGroups, setAllGroups] = useState<ImageGroup[]>([]);
  const [focusedIdx, setFocusedIdx] = useState(0);
  const [keptPaths, setKeptPaths] = useState<string[]>([]);
  const [loading, setLoading] = useState(true);
  const [submitting, setSubmitting] = useState(false);

  const thumbRefs = useRef<(HTMLDivElement | null)[]>([]);

  useEffect(() => {
    setLoading(true);
    Promise.all([
      fetch(`/api/groups/${groupId}`).then((r) => r.json()),
      fetch('/api/groups').then((r) => r.json()),
    ])
      .then(([detail, groups]: [{ group: ImageGroup; images: ImageRecord[] }, ImageGroup[]]) => {
        setGroup(detail.group);
        setImages(detail.images);
        setAllGroups(groups);
        setKeptPaths([]);
        setFocusedIdx(0);
      })
      .catch(() => toast.error('Failed to load group'))
      .finally(() => setLoading(false));
  }, [groupId]);

  // Scroll focused thumbnail into view when it changes
  useEffect(() => {
    thumbRefs.current[focusedIdx]?.scrollIntoView({
      behavior: 'smooth',
      block: 'nearest',
      inline: 'center',
    });
  }, [focusedIdx]);

  function toggleKeep(filePath: string) {
    setKeptPaths((prev) =>
      prev.includes(filePath) ? prev.filter((p) => p !== filePath) : [...prev, filePath],
    );
  }

  const handleSubmit = useCallback(
    async (keepPaths: string[]) => {
      setSubmitting(true);
      const recyclePaths = images
        .filter((img) => !keepPaths.includes(img.filePath))
        .map((img) => img.filePath);

      try {
        const res = await fetch(`/api/groups/${groupId}`, {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ keepPaths, recyclePaths }),
        });
        if (!res.ok) {
          const { error } = (await res.json()) as { error: string };
          toast.error(error);
          return;
        }
        const groupIndex = allGroups.findIndex((g) => g.id === groupId);
        const nextGroup = allGroups[groupIndex + 1];
        router.push(nextGroup ? `/review/${nextGroup.id}` : '/review');
      } catch {
        toast.error('Failed to save resolution');
      } finally {
        setSubmitting(false);
      }
    },
    [allGroups, groupId, images, router],
  );

  // Keyboard shortcuts: ← → navigate, Space toggle keep, Enter submit
  // focusedIdx is in deps so Space always toggles the currently focused image.
  useEffect(() => {
    function handleKey(e: KeyboardEvent) {
      // Don't steal from form inputs
      if (e.target instanceof HTMLInputElement || e.target instanceof HTMLTextAreaElement) return;

      if (e.key === 'ArrowLeft') {
        setFocusedIdx((prev) => Math.max(0, prev - 1));
      } else if (e.key === 'ArrowRight') {
        setFocusedIdx((prev) => Math.min(images.length - 1, prev + 1));
      } else if (e.key === ' ') {
        e.preventDefault();
        const img = images[focusedIdx];
        if (img) {
          setKeptPaths((prev) =>
            prev.includes(img.filePath)
              ? prev.filter((p) => p !== img.filePath)
              : [...prev, img.filePath],
          );
        }
      } else if (e.key === 'Enter') {
        e.preventDefault();
        handleSubmit(keptPaths);
      }
    }
    window.addEventListener('keydown', handleKey);
    return () => window.removeEventListener('keydown', handleKey);
  }, [images, focusedIdx, keptPaths, handleSubmit]);

  const groupIndex = allGroups.findIndex((g) => g.id === groupId);
  const focusedImage = images[focusedIdx] ?? null;

  if (loading) {
    return (
      <div className="flex h-[calc(100vh-2.75rem)] items-center justify-center">
        <p className="text-sm text-muted-foreground">Loading…</p>
      </div>
    );
  }

  if (!group) {
    return (
      <div className="flex h-[calc(100vh-2.75rem)] flex-col items-center justify-center gap-3">
        <p className="text-sm text-muted-foreground">Group not found.</p>
        <Link href="/review" className="text-sm text-primary underline underline-offset-2">
          ← Back to Review Queue
        </Link>
      </div>
    );
  }

  return (
    <div className="flex h-[calc(100vh-2.75rem)] flex-col overflow-hidden">
      {/* ── Action bar ── */}
      <div className="flex flex-none items-center gap-2 border-b bg-background px-4 py-2">
        <Link
          href="/review"
          className="text-sm text-muted-foreground hover:text-foreground"
        >
          ← Back to Review Queue
        </Link>

        <span className="mx-auto text-sm font-medium">
          Group {groupIndex >= 0 ? groupIndex + 1 : '?'} of {allGroups.length}
        </span>

        <div className="flex items-center gap-2">
          <Button
            size="sm"
            variant="outline"
            onClick={() => setKeptPaths(images.map((img) => img.filePath))}
          >
            Keep All
          </Button>

          <Dialog>
            <DialogTrigger render={<Button size="sm" variant="outline" />}>
              Discard All
            </DialogTrigger>
            <DialogContent>
              <DialogHeader>
                <DialogTitle>Discard all images?</DialogTitle>
                <DialogDescription>
                  All {images.length} image{images.length !== 1 ? 's' : ''} in this group
                  will be moved to the Recycle Bin. This cannot be undone.
                </DialogDescription>
              </DialogHeader>
              <DialogFooter showCloseButton>
                <DialogClose
                  render={
                    <Button
                      variant="destructive"
                      disabled={submitting}
                      onClick={() => handleSubmit([])}
                    />
                  }
                >
                  Discard All
                </DialogClose>
              </DialogFooter>
            </DialogContent>
          </Dialog>

          <Button size="sm" onClick={() => handleSubmit(keptPaths)} disabled={submitting}>
            Keep Selected & Continue →
          </Button>
        </div>
      </div>

      {/* ── Large preview ── */}
      <div className="flex flex-1 min-h-0 flex-col overflow-hidden">
        <div className="flex flex-1 min-h-0 items-center justify-center overflow-hidden bg-zinc-950/5 dark:bg-zinc-950/30">
          {focusedImage && (
            // eslint-disable-next-line @next/next/no-img-element
            <img
              key={focusedImage.filePath}
              src={imageUrl(focusedImage.filePath)}
              alt={basename(focusedImage.filePath)}
              className="max-h-full max-w-full object-contain"
            />
          )}
        </div>

        {/* Metadata row */}
        {focusedImage && (
          <div className="flex-none border-t bg-background px-4 py-1.5 text-xs text-muted-foreground">
            <span className="font-mono">{basename(focusedImage.filePath)}</span>
            <span className="mx-2">·</span>
            <span>
              {focusedImage.width} × {focusedImage.height}
            </span>
            <span className="mx-2">·</span>
            <span>{formatBytes(focusedImage.fileSize)}</span>
            <span className="mx-2">·</span>
            <span>{focusedImage.dpiX} DPI</span>
            <span className="mx-2">·</span>
            <span>
              {focusedImage.dateTaken
                ? new Date(focusedImage.dateTaken).toLocaleDateString()
                : new Date(focusedImage.fileMtime).toLocaleDateString()}
            </span>
          </div>
        )}
      </div>

      {/* ── Thumbnail strip ── */}
      <div className="flex h-[25vh] flex-none flex-row gap-1 overflow-x-auto bg-zinc-900 p-1">
        {images.map((img, idx) => {
          const isKept = keptPaths.includes(img.filePath);
          const isFocused = focusedIdx === idx;
          return (
            <div
              key={img.filePath}
              ref={(el) => {
                thumbRefs.current[idx] = el;
              }}
              className={cn(
                'relative h-full flex-none cursor-pointer overflow-hidden rounded-sm transition-opacity',
                isKept
                  ? 'ring-2 ring-green-500'
                  : cn(
                      'ring-1 ring-white/20',
                      isFocused ? 'opacity-100' : 'opacity-60 hover:opacity-90',
                    ),
                isFocused && 'opacity-100',
              )}
              style={
                img.width > 0 && img.height > 0
                  ? { aspectRatio: `${img.width}/${img.height}` }
                  : undefined
              }
              onClick={() => setFocusedIdx(idx)}
            >
              {/* eslint-disable-next-line @next/next/no-img-element */}
              <img
                src={imageUrl(img.filePath)}
                alt={basename(img.filePath)}
                className="h-full w-full object-cover"
              />
              {/* Keep checkbox overlay */}
              <input
                type="checkbox"
                checked={isKept}
                onChange={() => toggleKeep(img.filePath)}
                onClick={(e) => e.stopPropagation()}
                className="absolute left-1 top-1 h-4 w-4 cursor-pointer accent-green-500"
                aria-label={`Keep ${basename(img.filePath)}`}
              />
              {/* Green inset ring when kept */}
              {isKept && (
                <div className="pointer-events-none absolute inset-0 rounded-sm ring-2 ring-inset ring-green-500" />
              )}
            </div>
          );
        })}
      </div>

      {/* ── Keyboard hints ── */}
      <div className="flex flex-none items-center justify-center gap-5 border-t bg-background px-4 py-1 text-[10px] text-muted-foreground">
        <span>
          <kbd className="rounded border px-1 font-mono text-[9px]">←</kbd>{' '}
          <kbd className="rounded border px-1 font-mono text-[9px]">→</kbd> navigate
        </span>
        <span>
          <kbd className="rounded border px-1 font-mono text-[9px]">Space</kbd> toggle keep
        </span>
        <span>
          <kbd className="rounded border px-1 font-mono text-[9px]">Enter</kbd> submit
        </span>
      </div>
    </div>
  );
}
```
